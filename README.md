# Product and Category Management

Этот проект реализует простую систему управления продуктами и категориями с использованием классов `Product` и `Category`. Он позволяет создавать продукты, добавлять их в категории и отслеживать общее количество продуктов и категорий.

## Описание классов

### Product

Класс `Product` представляет продукт с следующими атрибутами:

- `name` (str): Название продукта.
- `description` (str): Описание продукта.
- `price` (float): Цена продукта.
- `quantity` (int): Количество продукта на складе.
